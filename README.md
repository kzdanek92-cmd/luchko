# Kent Telegram Bot

Бот подписочного сервиса общения с Кентами. Реализован на `aiogram` с локальной SQLite-базой для учёта подписок, чатов и жалоб.

## Возможности
- `/start` — приветствие и быстрый выбор тарифа.
- `/info` — правила сервиса и ограничения.
- `/status` — проверка подписки.
- `/kents` — список Кентов и открытие текстового чата без медиа.
- `/pay <day|week|month>` или кнопки — создание платежа ЮKassa (при отсутствии ключей активирует подписку в песочнице).
- Жалоба из любого диалога через кнопку «Пожаловаться».
- Логи чатов в базе: отправитель, содержимое и время.
- Админ-команды: `/admin`, `/add_kent`, `/remove_kent`, `/block`, `/complaints`, а также ответ Кента `/reply <user_id> текст`.

## Ограничения и модерация
- Разрешены только текстовые сообщения без медиа.
- Запрещены ссылки, телефоны, упоминания `@username`.
- Нет 18+ и интим-услуг. Нарушители блокируются.
- Все сообщения пишутся в логи; жалобы фиксируются для админов.

## Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Настройте переменные окружения:
   - `TELEGRAM_TOKEN` — токен бота (обязательно).
   - `ADMIN_IDS` — список Telegram ID администраторов через запятую.
   - `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY` — для реальных платежей (опционально). Без них подписка активируется в песочнице без оплаты.
   - `SUCCESS_URL` / `CANCEL_URL` — URL возврата из ЮKassa.
3. Запустите бота:
   ```bash
   python -m kentbot.bot
   ```

## Структура данных
- SQLite `kent.db` создаётся автоматически в каталоге пакета.
- Основные сущности: пользователи, Кенты, подписки, платежи, сообщения и жалобы.

## Примечания
- Платформа продаёт только доступ по подписке; выплаты третьим лицам не предусмотрены.
- Внутренний чат работает через одного бота, без обмена контактами и ссылками.
